# Season workflow pack (for Cursor)

Reference pack for the season workflow feature (already at `docs/season-workflow/…`).

1. Open `PROMPT.md` for the full build brief.
2. Implementation plan: `.cursor/plans/` (season workflow auction).
3. Build **one phase at a time** unless asked otherwise.

## Contents

| File | What it's for |
|---|---|
| `PROMPT.md` | The full build prompt: decisions, data model, rules, screens, stage locks, tests, phases, acceptance |
| `reference/season5-auction-rules.md` | Season 5 auction rules and numbers (purse, max bid formula, squad cap, leftover stage, re-bid rounds) |
| `reference/fixture-generator-notes.md` | Season 5 fixture timings, the back-to-back findings and the generator algorithm |
| `reference/registration-sample.csv` | Fake data with the real Google Form headers and the messy cases (duplicates, "Begineer", "Sr citizen", "Tower 21042") |
| `reference/auction-draw-reference.html` | The Season 5 draw tool (placeholder names), as a UX reference |
| `reference/*.png` | Projector player card, live purse board (sample data), draw screen, auction rules slide |
